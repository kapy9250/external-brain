# Recommend this "45 Thoughts About Agents"

URL: https://x.com/runes_leo/status/2029081154066723039

Recommend this piece "45 Thoughts About Agents" by Steve Newman, co-founder of Google Docs. It is very dense with information.

A few points that left a deep impression:
- Agents are the fastest evolving layer in the AI stack — models update every few months, but Claude Code can release several versions in a single day;
- However, what evolves even faster than agents is the user's own way of working.
- Naively throwing tasks at an agent might actually decrease productivity. The key is to let the agent self-verify — enabling it to run its own tests to prove "I did it right," rather than having you check it round after round.
- The impact of AI is the product of 8 factors (pre-training, post-training, inference compute, agent scaffolding, application design, user capability, workflow refactoring, adoption rate), all advancing simultaneously. This wave of revolution is only 1/3 of the way through.
